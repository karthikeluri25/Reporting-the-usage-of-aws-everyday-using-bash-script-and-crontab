# Reporting-the-usage-of-aws-everyday-using-bash-script-and-crontab
This project helps you get a daily report of your AWS usage with a simple Bash script. The script runs automatically using crontab and shows details like running instances, s3 buckets, lambda and iam users.  It’s an easy way to keep track of your AWS usage every day without checking the console manually.

I have attached the script file (demoscript.sh) & crontab file for automating the script and generating report
